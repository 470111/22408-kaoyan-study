## 阶段一：基础

### 范围

- 高数 **30讲第11–15讲**（数二跳过16–18）
- **1000题基础篇 A组**（同步讲次）
- **计算练习** 30min/天
- **不刷880**

### 每日模板（数学 3.75h，含政治 Redistribution）

| 时段 | 内容 |
|------|------|
| 08:00–10:00 | 30讲新讲 + **例题手算** |
| 10:15–11:15 | 1000题A组（或当日讲次错题） |
| 11:15–11:45 | 计算练习（极限/导数/积分） |
| +0.25h | 1000题加做 / 错题（政治省出时间） |

### 基础阶段检验（达标日，目标 6.19，最晚约 6.25）

- [ ] 30讲 **11–15讲**：视频 + **例题手算**（见 [30讲进度追踪.md](30讲进度追踪.md)）
- [ ] 1000题基础篇 **≥70%**（见 [1000题追踪.md](1000题追踪.md)）
- [ ] **5.31** 基线：2020选填已测并记入 [../01-baseline/基线测评记录表.md](../01-baseline/基线测评记录表.md)
- [ ] 错题本持续更新

**未达标**：不进入二轮，继续本模板（见 [../数学408-6月每日细表.md](../数学408-6月每日细表.md) 6.20–6.25 基础缓冲说明）。

### 基线测评分支（5.31 前完成）

| 2020选填得分 | 基础阶段调整 |
|--------------|--------------|
| **≥50/80** | 按标准日表推进 |
| **40–49** | 每天计算 **+30min**（三大计算） |
| **<40** | 只做 **1000题A组 + 例题**，不加量、不开B组 |

## 阶段二：二轮

### 范围

- **30讲讲义/笔记回看**（薄弱讲优先，按基线错因）
- **880** 按章推进（高数 → 线代）
- **1000题**：错题二刷 / 基础篇收尾至80%，**不开强化篇新章**

### 7.1 – 7.9（二轮内，非36讲强化）

- **30讲线代第1–6讲** + 1000题线代A组
- **880线代篇** 启动
- 7.10 前 **不上36讲**

### 每日模板（7月起数学权重 5.0h）

| 块 | 内容 | 时长 |
|----|------|------|
| 块1 | 30讲复习 1–2讲 / 线代新讲（7.1–7.9） | ~1.5–2h |
| 块2 | **880** 当日章节 | ~1–1.5h |
| 块3 | 1000题错题 / 计算 | ~0.5–1h |

### 7.9 检验（二轮收尾）

- [ ] 880 高数核心章过一遍
- [ ] 线代30讲6讲 + 线代880已启动
- [ ] 1000题基础篇 **≥80%** 为佳

## 阶段三：强化

### 范围

- **张宇36讲**（高数 + 线代强化）
- **1000题强化篇**（B组等）
- **880** 综合 / 错题
- **周六**：数二真题（7.28起2021等）

### 7.10 – 7.31

对齐 [../数学408-7-8月每日细表.md](../数学408-7-8月每日细表.md) 408 计网段；数学列为36讲+1000强化+880。

### 8.31 检验

- [ ] 36讲高数+线代强化完成
- [ ] 1000题强化篇 ≥80%
- [ ] 2021–2023数二均分 ≥100
