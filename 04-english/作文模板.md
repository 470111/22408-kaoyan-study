# 作文模板（9月前定型）

> 英二：小作文10分 + 大作文15分 = 25分  
> 目标：模板熟练，考场不现场发明句式 | **8月底前定稿**

---

## 小作文 8 类（每类1套模板）

| 类型 | 模板状态 | 练写次数 | 掌握 |
|------|----------|----------|------|
| 建议信 | ☐ | /2 | ☐ |
| 道歉信 | ☐ | /2 | ☐ |
| 投诉信 | ☐ | /2 | ☐ |
| 感谢信 | ☐ | /2 | ☐ |
| 邀请信 | ☐ | /2 | ☐ |
| 祝贺信 | ☐ | /2 | ☐ |
| 推荐信 | ☐ | /2 | ☐ |
| 通知/告示 | ☐ | /2 | ☐ |

**格式必背**：称呼、正文结构、结尾敬语、署名

---

## 大作文模板

| 类型 | 模板状态 | 练写次数 | 掌握 |
|------|----------|----------|------|
| 图表类（柱状/折线/饼图） | ☐ | /3 | ☐ |
| 议论类（观点/现象） | ☐ | /3 | ☐ |

**结构**：描述/现象(2–3句) → 分析原因(2–3句) → 观点/建议(2–3句)

## 小作文万能框架（填空式）

```
Dear ______,

I am writing to ______ [目的]. 

First, ______ [要点1]. Second, ______ [要点2]. 

I would appreciate it if you could ______ [期待]. 

Yours sincerely,
Li Ming
```

*请根据所选老师课程，替换为正式模板*

---

## 大作文图表框架

```
The chart/graph clearly shows that ______ [总体趋势].

To begin with, ______ [数据描述1]. In addition, ______ [数据描述2].

There are several reasons for this phenomenon. Firstly, ______. Secondly, ______.

In my opinion, ______ [观点/建议].
```
