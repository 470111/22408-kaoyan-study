# CO–OS 联动笔记（一页纸框架）

> 985综合题核心链路：Cache → 主存 → 虚拟内存 → TLB → 页面置换  
> 目标：闭卷能画、能算、能讲

---

## 1. 存储层次总图

```
CPU寄存器
    ↓
Cache (L1/L2/L3)  ←→  CO: 映射方式(直接/全相联/组相联)
    ↓
主存 (DRAM)       ←→  CO: 地址结构、芯片扩展
    ↓
虚拟内存 (磁盘)   ←→  OS: 页面/段、页面置换算法
    ↓
TLB (快表)        ←→  CO+OS: 虚实地址转换加速
```

---

## 2. 虚实地址转换流程

| 步骤 | 内容 | 涉及科目 |
|------|------|----------|
| 1 | 逻辑地址 → 页号 + 页内偏移 | OS |
| 2 | 页号 → 查页表 → 物理块号 | OS |
| 3 | TLB命中？是则跳过页表 | CO+OS |
| 4 | 物理地址 = 块号×块大小 + 偏移 | OS |
| 5 | 物理地址 → Cache映射 → 命中/缺失 | CO |
| 6 | Cache缺失 → 主存/磁盘 | CO+OS |

**必练**：给定逻辑地址，手算全程（含TLB、页表、Cache三层）

---

## 3. Cache 与主存（CO）

| 概念 | 要点 | 易错 |
|------|------|------|
| 直接映射 | 块号 mod Cache行数 | 冲突率高 |
| 全相联 | 任意块→任意行 | 成本高 |
| 组相联 | 组内全相联 | 最常考 |
| 写策略 | 写直达/写回 | 与一致性 |
| 替换算法 | LRU/FIFO/随机 | 手算题 |

---

## 4. 虚拟内存与页面置换（OS）

| 算法 | 规则 | 缺页次数手算 |
|------|------|-------------|
| FIFO | 先进先出 | 必练 |
| LRU | 最久未用 | 必练 |
| OPT | 理论最优 | 了解 |
| CLOCK | 二次机会 | 常考 |

**与Cache区别**：页面置换管主存↔磁盘；Cache替换管Cache↔主存

## 5. PV 操作模板（OS大题）

### 生产者-消费者
```
semaphore mutex=1, empty=n, full=0;
Producer: P(empty)→P(mutex)→生产→V(mutex)→V(full)
Consumer: P(full)→P(mutex)→消费→V(mutex)→V(empty)
```

### 读者-写者 / 哲学家就餐
- 各准备1套模板，考场上改变量名即可
